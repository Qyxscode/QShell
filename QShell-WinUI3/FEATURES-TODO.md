## 1. IPv6 字面量连接修复（已完成）

**实现**（2026-10-23）：
- `ssh.rs` 新增 `connect_tcp()`：`(host, port).to_socket_addrs()` + 每个地址 `connect_timeout(8s)` 轮询；`start_ssh_session` 改用它，支持 IPv6 字面量并消除 21 秒卡顿。
- `probe.rs` 改为 `(clean_host, target_port).to_socket_addrs()`。
- 验证：`cargo test` 全绿；域名/IPv4 路径不变。

**原因**：地址用字符串拼接，未处理 IPv6 需要方括号的规则。

| 位置 | 现状 | 修复 |
|---|---|---|
| `ssh.rs:89` | `format!("{}:{}", host, port)` | 改为 `TcpStream::connect((host.as_str(), port))`，或 `to_socket_addrs()` |
| `probe.rs:16` | `format!("{}:{}", clean_host, target_port)` | 改为 `(clean_host.as_str(), target_port).to_socket_addrs()` |

**顺带修复**：SSH 主连接目前使用 `TcpStream::connect`，没有连接超时，不可达地址会卡到系统默认（约 21 秒）。建议改成 `connect_timeout` + 多地址轮询（`sftp.rs:46-54` 已有正确写法）。

**验收**：
- 填 `2001:db8::1` 能连接，且 `[2001:db8::1]` 旧写法仍兼容；
- 域名、IPv4 行为不变；
- 不可达 IPv6 地址 8 秒内报错，不再长时间卡住。

## 2. 本地终端（PowerShell / CMD）支持（已完成）

**需求**：在「添加主机」里增加本地 Shell 类型，可选 **PowerShell** 与 **CMD**，打开后是一个本地终端会话，行为与现有终端一致（颜色、光标、复制粘贴、字体、主题等）。

### 2.1 数据模型

- 协议枚举从 `"ssh" | "telnet" | "serial"` 扩展为 `"ssh" | "telnet" | "serial" | "local"`
- 本地类型增加子字段 `local_shell: "powershell" | "cmd"`（默认 `powershell`）
- 可选：`local_cwd`（起始目录）、`local_args`（额外参数）

### 2.2 后端

- 新增 `local_shell_service.rs`，与 `serial_service.rs` 同构：
  - 用 **ConPTY**（Windows 10 1809+）创建伪终端，推荐 `portable-pty` crate（wezterm 维护），它会自动使用 ConPTY；
  - 进程：`powershell.exe -NoLogo` 或 `cmd.exe`；工作目录取 `local_cwd`；
  - 复用 `GenericStreamManager`（writer + 读线程 + `ssh-data-{sid}` / `ssh-closed-{sid}` 事件）；
  - 终端尺寸通过 `resize` 同步到 PTY（ConPTY 支持）；
  - 结束会话时确保子进程被终止（避免僵尸进程）。
- 命令注册：`start_local_shell_session` / `write_generic_session`（复用）/ `resize_generic_session`（复用）/ `close_generic_session`（复用）。

### 2.3 前端

- 「添加主机」协议下拉增加 **本地终端**，选中后显示「Shell 类型：PowerShell / CMD」；
- 会话创建时走本地启动命令；
- 本地会话**隐藏**右侧 SFTP 面板与监控卡片（无远程主机概念），或显示"本地会话不支持"；
- 标题栏/标签页显示 `PowerShell` 或 `CMD` 图标与名称；
- 底部状态栏不显示远端延迟。

### 2.4 兼容与限制

- 仅 Windows 支持（ConPTY）；其它平台可用 `forkpty`（本次不做）；
- 本地终端不受 SSH 主题/字体影响？——应共用现有 `terminalSettings`，保持体验一致；
- 安全性：本地终端等于直接执行命令，属预期行为，但需在首次使用时提示一次。

### 2.5 验收

1. 添加本地主机，选 PowerShell，打开后能执行 `Get-ChildItem`，颜色正常；
2. 选 CMD，执行 `dir` 正常；
3. 调整窗口大小，`mode con` / `$Host.UI.RawUI.WindowSize` 随之变化；
4. 关闭标签，任务管理器里 `powershell.exe`/`cmd.exe` 子进程被结束；
5. 本地会话不显示 SFTP 与监控面板。

## 26. 广播台（底部抽屉 · 群发命令）

**状态**：✅ 已实现（测试版 177，待回归验证）

**定下来的形态**（2026-10-27，含 172~177 的排版与动画修正）：

- 入口：底部状态栏右侧按钮，SVG 双箭头图标 +「广播」+ 台数徽章；有参与会话时边框/文字变强调色。按钮宽度随内容，图标走 flex 居中。
- 面板：与命令面板同构的底部抽屉，**固定高度 340px**（命令面板同一档）、参与布局。
- **动画**：与命令面板完全相同 —— `height 0.8s cubic-bezier(0.4,0,0.2,1)` + `opacity 0.6s ease`；两个抽屉同时一开一合，高度互补，终端区高度全程不变。
- **边框/线条**：
  - 底色 `--bg-card`，顶部一条 `--border-card` 的线（与主框体边框同色同粗，看起来是主框体内部的一道线）；
  - 底边线常驻但透明，`is-open` 时上色 —— 于是展开动画全程都有下沿轮廓，不需要"假线 + 销毁"；
  - 面板展开时，`.terminal-viewport.bp-open + .terminal-status-bar` 的顶线让位，避免面板底边与状态栏顶边叠成 2px。命令面板用同一套机制（`palette-open`）。
- 排版：**主机列表 2 列网格在上**（`grid-auto-rows: minmax(0,1fr)` 等分剩余高度，卡片随面板变高）、**命令输入框在下**（固定 68px）。
- **按钮一律用 `.qp-toggle-btn`**（命令面板同款：描边 + 极淡底 + 11px 字，未着色），包括「全选已连接 / 全不选 / ✕ / 发送」。
- 发送行为（v177 落实）：
  - 逐台 `write_ssh_session` / `write_generic_session`（按 `isGenericProtocol` 分流），**单台失败不中断其余台**；
  - 多行输入按行补 `\r`，shell 里逐条执行；
  - 只读会话跳过并计入失败；已断开的会话跳过；
  - 会话关闭时 `removeBroadcastTarget()` 同步移出集合；
  - 成功后 `recordCommand()` 记入命令历史；有失败时保留输入内容，提示「已发送 N 台，失败：xxx」；
  - 发送中按钮显示「发送中…」并禁用。
- 目标粒度：按会话（不只是当前可见屏），未上屏的会话标「未上屏」；头部显示「N 台在线」。

**后续可选增强**：

1. 逐台结果目前用一行提示汇总（成功 N 台 + 首个失败原因）；若需要更细，可在每个主机行上标状态（成功 ✓ / 失败 ✗ + 原因）。
2. 发送前二次确认（例如超过 3 台时）——运维防手滑。
3. 快捷键唤起（例如 Ctrl+Shift+B）。

**文件位置**：`src/App.vue`（`showBroadcastPanel` 等状态 + `sendBroadcast`）、`src/styles/app.css`（`.broadcast-panel` / `.bp-*` / `.status-bc-*`）。

## 评估记录：Win7 移植可行性（2026-10-27，仅评估不实施）

**结论：当前技术栈不可移植到 Win7。**

硬性障碍：
1. **WebView2 从 109 版（2023-01）起不再支持 Win7/8/8.1**，且已停止安全更新；Tauri 2 要求更新的 WebView2 → 界面无法渲染。
2. Tauri 2 官方不支持 Win7（依赖 WebView2 新特性）。
3. 新版 Rust std / tokio 等依赖 Win7 缺失的 API，需 patched toolchain。

备选方案（均不推荐）：
| 方案 | 代价 | 风险 |
|---|---|---|
| 降级 Tauri 1 + WebView2 109 | 中 | 组件全部 EOL，无安全更新 |
| Electron 22 | 大（重写壳） | EOL，包体大 |
| 原生 WPF/Win32 重写 | 极大 | 数月工作量 |

**替代方向（未来可选）**：Web 端模式 —— Rust 侧起 axum 服务，前端 Vue/xterm 全复用，只替换 IPC 层为 HTTP/WebSocket，浏览器（含手机）即可访问。工作量约 2~3 周，需配认证与 TLS。串口与本地终端在 Web 模式不可用。

**当前决定**：先完善全部功能，Win7 与 Web 端均暂缓。

**后端依赖盘点（基于当前 Cargo.toml）**

3. 后台保活：前台服务 + 常驻通知 + 断线重连适配移动网络（1 周）
